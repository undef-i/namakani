Blowfish constants (internal/tuta/blowfish_tables.go)
Source: https://github.com/golang/crypto (golang.org/x/crypto/blowfish)
License: BSD 3-Clause "New" or "Revised" License

The Blowfish P-array and S-box constants in internal/tuta are the
hexadecimal digits of pi published in golang.org/x/crypto/blowfish
(Copyright (c) 2009 The Go Authors; BSD 3-Clause, see the golang.org/x/crypto
entry elsewhere in this file). They are reproduced because the exported
x/crypto/blowfish API does not support the repeated key expansion schedule
that Tuta's bcrypt password KDF requires.

Tuta Mail driver provenance (internal/tuta)
Source: https://github.com/tutao/tutanota (client version 362.261020.0)
License: GNU General Public License v3.0

The protocol implementation in internal/tuta is a translation of the
official Tuta client (tutao/tutanota), which is distributed under the
GNU General Public License v3.0, the same license as this project.
Translated material includes the password KDF branches (bcrypt and
Argon2id), the group key chain and session key resolution, the
symmetric cipher formats (legacy CBC, CBC-then-HMAC and BLAKE3 AEAD),
the TutaCrypt hybrid encapsulation (X25519 + ML-KEM-1024), the entity
REST wire format and the event WebSocket protocol.

internal/tuta/testdata/CompatibilityTestData.json is copied verbatim
from the tutao/tutanota test suite (test/tests/api/worker/crypto/
CompatibilityTestData.json) and is used as unit test fixtures under the
same license.
